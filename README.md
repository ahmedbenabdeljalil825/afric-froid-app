Afric Froid — Industrial IIoT Monitoring Platform
A fullstack industrial IoT platform built entirely using AI coding agents (Claude Code, Cursor, Google Antigravity, OpenCode, Codex) — zero manual code.
Features

Real-time telemetry monitoring (Temperature, Pressure, Power Usage) via MQTT
Remote equipment control with secure PLC communication
Dynamic widget designer for custom client dashboards
Multi-tenant architecture — each company manages its own fleet
Bilingual interface (FR/EN)
Android native version via Capacitor

Stack: React · TypeScript · Supabase · MQTT · Tailwind · Vite · Vercel
Live demo: https://afric-froid-portal.vercel.app
